project.

## Developer Certificate of Origin

Contributions should use the Developer Certificate of Origin sign-off. Add a
`Signed-off-by` line to each commit:

```bash
git commit -s
```

That sign-off means you have the right to submit the contribution and agree to
license it under Apache-2.0.

## Contribution Guidelines

- Keep changes focused and easy to review.
- Add or update tests for behavior changes.
- Do not commit private keys, customer secrets, encoded customer projects, or
  generated vendor secret files.
- Preserve existing copyright, license, trademark, and attribution notices.
- Mark large generated files clearly, or avoid committing them unless they are
  required for the project.
